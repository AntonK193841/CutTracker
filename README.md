# CutTracker

Система учета и расчета раскроя листового металла.

CutTracker предназначен для инженеров судостроительного цеха и позволяет
автоматизировать работу со спецификациями деталей, рассчитывать размещение
деталей на металлических листах и вести учет доступных материалов.

---

## Задача

При производстве деталей из листового металла необходимо решить две задачи:

1. определить, как разместить детали на листе;
2. минимизировать площадь отходов.

Дополнительная проблема — учет остатков металла на складе.

В традиционном процессе инженер может использовать Excel и VBA-макросы
для обработки спецификации и ручного расчета.

CutTracker переносит этот процесс в отдельное приложение:

Excel → Python importer → REST API → PostgreSQL

---

## Основные возможности

- добавление деталей;
- хранение материалов;
- учет количества листов на складе;
- расчет площади деталей;
- расчет размещения деталей на листе;
- учет площади отходов;
- расчет процента использования листа;
- сохранение результатов раскроя;
- импорт спецификаций из Excel;
- REST API;
- Swagger/OpenAPI;
- web-интерфейс.
